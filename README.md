# Kinoza

Un outil pour planifier des programmes d'exercices, pour les entraîneurs, les kinésiologues et les autres professionnels du mouvement.
Il fonctionne dans le navigateur, sans compte et sans installation.

- Banque d'exercices illustrés, avec filtres par groupe musculaire
- Dossiers clients et plusieurs programmes par client
- PDF du programme en un clic
- Dossiers chiffrés, verrouillage des programmes et notes datées non modifiables
- Outils pour la Loi 25 : consentement, accès, rectification, conservation et destruction

## Vos données

Les dossiers clients restent uniquement sur votre appareil, chiffrés dans le navigateur.
Rien n'est envoyé sur Internet et ce dépôt ne contient aucune donnée de client.
Exportez régulièrement une sauvegarde chiffrée et gardez-la en lieu sûr : sans elle,
les dossiers sont perdus si l'appareil brise ou si le navigateur efface ses données.
